# What's new in ATS

## 0.1.8
- A new side list when you evaluate: one dot per paragraph that can be improved, coloured by state (not chosen, chosen, already ATS-friendly). Tap to jump straight to the paragraph – handy in long CVs.
- Clearer when the score is already 100: a note explains that the structure score has a ceiling and the suggestions sharpen the wording instead, with a tip to add a job ad for a keyword score.

## 0.1.7
- Continue where you left off: if you start improving a CV but do not finish, the work is saved automatically. The card shows "In progress" and how many suggestions you chose, and when you open the document again your choices and fills come back without fetching the AI suggestions again.
- A Start over button in the evaluation view clears the draft and begins from the original.
- Save as PDF: a clean document with selectable text an ATS can read. (A PDF cannot be read back into the app.)

## 0.1.6
- Document cards now show a real miniature built from the document's own paragraphs: the name, headings and tables show, so every CV looks different.
- New region choice under Settings. Pick Sweden/Europe or the Gulf states. In Gulf mode a photo costs no points, personal details (nationality, visa/Iqama/QID, availability) are checked, longer CVs are accepted and Arabic headings are recognised.
- When you save you can choose .docx or .odt. The same format keeps the layout; the other builds a clean, ATS-safe document.
- Settings now open from the gear in the corner on every tab. The menu has three tabs: Home, Evaluate and Documents.
- A new in-app picker lists your CVs in Download/ATS, newest first, with tabs for All, Original and Improved. "Browse the phone" opens the system picker.
- Uninstall guide under Settings: back up settings and scores, keep or delete the folder, and restore from a backup.
- Protection: the app starts only if it is signed with the developer's key, and the code is protected with R8.
- The keyboard no longer covers the field you are typing in, and a preview shows how the paragraph will read.

## 0.1.5
- A CV you put in Download/ATS from a computer or over USB is now found automatically. The list is read again when you open the app or go to Documents, and the app looks by file extension instead of file type, so nothing is hidden.
- AI suggestions are steadier for long CVs: the text is split into smaller requests so the answer is not cut off, with a timeout and one automatic retry if the connection drops. This fixes "the answer could not be read" and "no connection".

## 0.1.4
- The API key field says clearly what goes in it: "Enter your Claude (Anthropic) API key here".

## 0.1.3
- The API key is explained in the app: what it is, what it costs and, step by step, how to get one. The guide shows right away under Settings › AI suggestions when no key is saved, and the manual has its own section.
- The app tells you when a pasted key does not look like a key from Anthropic.

## 0.1.2
- The app starts in English. Swedish can be chosen under Settings › Language.

## 0.1.1
- The Download/ATS folder is created right away when the app starts for the first time, with a short note (ATS.txt) in it. Before, the folder only appeared when the first CV was saved.

## 0.1.0
- First version of ATS: evaluate your CV in Word (.docx) or ODT and get an ATS score from 0 to 100.
- AI suggestions for every paragraph that can be improved, with an honesty lock: the AI never makes up facts, and if a number is missing it leaves a placeholder for you to fill in.
- Compare before and after, and save the improved document as a new file in Download/ATS. The original is never changed.
- My documents with the score in the corner, three demo CVs to try, dark and beige themes, Swedish and English, a manual and in-app updates.
